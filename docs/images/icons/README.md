# 아키텍처 아이콘

AWS 서비스·리소스 아이콘은 [AWS 공식 아키텍처 아이콘](https://aws.amazon.com/architecture/icons/)을 사용한다.
RDS·Secrets Manager·Internet Gateway·Private Subnet·ECS·ECR·Lambda·Scheduler·Container·Task·Public Subnet은 2026-07-31 패키지에서 가져왔다.
나머지 AWS 아이콘과 Terraform·브라우저 표식은 기존 아키텍처 파일에서 추출했다.
Terraform 표식의 출처는 [HashiCorp 공식 로고](https://www.hashicorp.com/en/brand/hcp-product-logos)다.
브라우저 표식은 프로젝트의 벡터 도형이다.
`duckdns.png`와 `github.png`는 2026-10-22에 사용자가 첨부한 이미지다. 원본을 그대로 사용한다.
기존 DuckDNS용 지구본은 현재 그림에서 사용하지 않는다.
그림에 사용하는 아이콘에는 글자와 숫자를 넣지 않는다.

`scripts/render-architecture.py`가 아이콘을 HTML과 draw.io에 포함한다.
외부 이미지 URL을 조회하지 않고 그림을 열 수 있다.
